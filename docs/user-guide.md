# 用户指南

这个仓库的主要用法是：**编辑配置 → 运行程序 → 读取文本结果 → 画图**。按[首页](../README.md)完成一次后，再逐步修改参数。

## 三个概念

**钟差/相位**是时钟相对参考时间的偏离，单位秒。`1e-9` 秒等于 1 纳秒。频率偏差表示钟差增长的快慢；时钟有随机噪声，所以单只钟在不同平均时间上的表现会不同。

**PFD** 是两只钟之间的直接比对。本案例取“钟 A − 钟 B”，反方向取相反数。四只钟全互连共有 6 对比对，不涉及轨道、光行时或 STK。

**组合时间尺度（Ensemble/IEM）** 是程序根据多只钟的比对信息得到的共同时间参考。用它与原始钟的 ADEV 比较，可以观察组合的稳定度表现。

## 每一步使用哪些文件？

```text
file_table
  ├─ Timescale.cfg → 模式、时间、输入路径、结果路径
  ├─ session.obj  → 对象、观测与噪声假设
  └─ svinf.dat / leap.sec / pan_info → 基础表
          ↓
GstarTimescale.exe 读取 CLK 和 PFD
          ↓
results/IEM.txt、SIM*.txt、gstar.log
          ↓
tools/plot_results.py
          ↓
figures/phase.png、adev.png 及 analysis/ 数值表
```

示例生成脚本只负责首次准备数据和配置。数据已经就绪后，改配置、求解、绘图三个步骤各自执行，互不替代。

## 一个实验目录

```text
Runs/manual_case/
  config/       本次实际使用的配置和基础表
  clocks_raw/   示例生成器保存的原始仿真钟差
  clk/          标准钟差输入
  pfd/          双向比对观测
  logs/         可选的控制台日志
  results/      核心写出的文本结果和 gstar.log
  figures/      独立脚本画出的相位与 ADEV
  analysis/     相位原值、ADEV 数值和绘图设置记录
```

结果位置由配置中的 `Project directory` 决定，图片位置由绘图脚本的 `OUTPUT_DIR` 或 `--output` 决定。默认都放在同一个实验目录内，方便找到和比较。

## 默认案例

| 设置 | 值 |
|---|---|
| 四只钟 | SIM1/SIM2 为 CSAC，SIM3/SIM4 为 mRO |
| 输入对象编号 | 0101～0104；CLK 使用 101～104 |
| 时间 | 2026-01-01 起，10 天，10 秒采样 |
| 每钟输入点数 | 86400 |
| 观测 | PFD，四钟全互连 |
| 解算 | centralized、GREENHALL、2 个趋势状态、0 个谐波状态 |

GPST 是实验时间系统，不是电脑本地时间。默认时钟参数是研究示例，不是某款设备的实测标定值。

## 怎样做一次参数对比？

1. 先用默认配置运行并画图。
2. 保存这份配置；为新实验指定新的 `Project directory`。
3. 只改一个参数，例如噪声假设或秩亏补偿方法，然后直接运行 exe。
4. 给绘图脚本指定新结果目录，再比较两次曲线。

改 `session.obj` 只会改变求解器的假设。若要改变观测数据本身的噪声，需要准备新的 CLK/PFD。修改开始时间和时长时，应使用覆盖相应时段的输入。

无需使每个数字与示例完全相同，先理解参数怎样参与计算、结果怎样得到。进一步的文件说明见[结果指南](results.md)，参数字段见[配置指南](configuration.md)。
