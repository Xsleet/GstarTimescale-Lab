# 如何读结果

## 先看报告是否完整

正常完成后会提示 `PASS`，生成 `report.html` 与 `summary.json`。这个 PASS 表示输出格式、时间连续性、有限数值、日志以及分析流程通过检查，**不是物理模型正确或算法性能最优的证明**。

10 天案例每钟输入 86,400 点。当前默认入口输出的公共有效区间为第 30 到 863,990 秒，共 86,397 点；前端边界受插值和初始化影响。五条曲线必须使用这同一段数据。

## 第一张图：相位随时间变化

相位原始单位为秒；显示时转换为纳秒（1 ns = 10⁻⁹ s）。报告每条曲线减去各自首个有效相位，便于放在一起观察；CSV 保留实际输出相位。不要从显示曲线的零点判断绝对同步精度。

HTML 相位图为控制体积会保留分桶极值进行抽样显示，CSV 和 ADEV 仍使用所有公共有效样本。相位“看起来更平”不足以证明频率稳定度更好。

## 第二张图：五条 Allan 偏差曲线

- 横轴 τ：平均时间，单位秒，使用对数刻度。
- 纵轴 ADEV：分数频率的 Allan 偏差，无量纲，使用对数刻度。
- SIM1、SIM2、SIM3、SIM4：四只原始钟，**不是减去 Ensemble 后的残差**。
- Ensemble：选定 IEM 输出对应的组合时间尺度。

在相同 τ、同一数据区间和相同处理方式下，ADEV 更低表示该尺度上的频率波动更小。不同 τ 反映不同时间尺度的表现，不能只看一个点给时钟或算法排总名次。

图形复用 DataProcess 的既有频率稳定度分析单元，使用非重叠 `allantools.adev`。不是 OADEV、MDEV 或 TDEV；不要混用指标名称。来源和文件哈希见 [分析快照说明](../tools/dataprocess_snapshot/README.md)。

## 数值表比“看图读数”更适合写报告

| 文件 | 用途 |
|---|---|
| `phase.csv` | 公共区间的四只钟与 IEM，相位单位秒 |
| `analysis/adev.tsv` | 默认倍频 τ 网格上的五条曲线、误差估计和有效项数 |
| `analysis/stability_summary.tsv` | 指定 τ 的直接计算结果，适合定量比较 |
| `analysis/dataprocess_frequency_cell.tsv` | 既有分析单元输出及复用记录 |
| `analysis/validation_report.txt` | 本次检查摘要 |
| `figures/adev.png/.pdf/.svg` | 适合报告、打印或进一步排版的图片 |

目标 τ 为 10、30、100、300、1000、3000、10000、30000、86400 秒。短实验会自动排除无法计算的长 τ。每个目标点都直接计算，不是从相邻曲线点插值得到。

`sample_count` 是参与非重叠 ADEV 的二阶差分项数，不是相位总点数，也不是独立自由度。10 天默认案例在 τ=86400 秒处只有 **8 项**，长 τ 的结论需谨慎对待。`adev_error` 是 AllanTools 返回的误差估计，本项目没有把它转换为严格的置信区间。

## 分布式结果的额外注意

`distributed_ci` 可能产生四个节点 IEM。自动报告选取排序后的第一个 IEM，并在 HTML 和 `summary.json` 中明确记录路径；其它输出也检查完整性。单个选定节点的五线图不等于所有节点都达到同样性能。跨节点比较需要另行分析，不要把这张图标成“全网平均”。

## 可以写进实验报告的结论

推荐格式：“在给定的合成模型、种子、架构和公共时间区间内，τ=… s 时 Ensemble ADEV 为…，与最佳单钟相比的比值为…，有效项数为…。”

进一步研究需要多个种子、参数误差和不同观测条件。当前案例没有物理设备标定，也没有注入额外 PFD 测量噪声，不能直接替代真实时钟系统试验。
